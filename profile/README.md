# 専修大学 2026年度生亀プロジェクト

## Project: IKU NAVI
専修大学生田キャンパスを対象とした、AR対応ナビゲーションWebアプリの開発・運営プロジェクト。

## Features
- ハイブリッドマップ: 屋外（Google Maps）と屋内（SVGフロアマップ）の自動切り替え
- ステップナビゲーション: 実写画像と地図を同期させた経路案内
- 経路探索: ダイクストラ法を用いたエレベーター対応最短経路算出
- システム運用: VPS、Docker、Cloudflareを用いた本番環境の構築

## Tech Stack
- Frontend: HTML, CSS, JavaScript, Google Maps API
- Backend: Python, Flask, Gunicorn, Pandas, NetworkX
- Infrastructure: Docker, Nginx, Cloudflare Tunnels, ConoHa VPS
